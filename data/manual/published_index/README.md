# Published index values (manual, git-ignored CSVs; D59, B7)

Only for an index history you hold under a licence that permits it. The
Silicon Data terms forbid storing site content without consent. The CSVs are
git-ignored.

Columns (header row required):

    index_name,as_of_date,value
    SDH100RT,2026-11-10,2.91

`index_name` is `SDH100RT` (GPU1) or `SDB200RT` (GPU2). Without these files,
claim 7 runs only its calendar-spread strategy (FP-B), which needs futures
prices alone.
